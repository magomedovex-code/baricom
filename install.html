Установка Baritone

Нужен Minecraft 1.21.11 с Fabric. Если у тебя уже стоит Litematica 0.26.11, Fabric уже есть.

Какой файл качать

Версия мода должна совпадать с версией игры. Для Minecraft 1.21.11 это Baritone 1.17.0.

26.11.18.0

На странице релиза много файлов. Нужен один: baritone-api-fabric-1.17.0.jar. Файлы с forge, neoforge и unoptimized не бери.

Скачать .jarСтраница релиза

Куда положить

  1. Открой папку модов

    Нажми Win + R, вставь %appdata%\.minecraft\mods и нажми Enter. Если играешь через другой лаунчер, открой папку модов своего профиля.

  2. Перетащи туда файл

    Он должен лежать рядом с Litematica и MaLiLib.

  3. Перезапусти игру

    Полностью закрой Minecraft и запусти снова.

Проверка

Зайди в мир, открой чат и напиши:

#help
[Baritone] Список команд: help, set, goal, goto, path, mine, sel …
Работает?

Дальше переходи к расчистке области или посмотри все команды.
