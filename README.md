# baricom

Гайд по [Baritone](https://github.com/cabaletta/baritone) на русском — одна страница-«спуск» от поверхности (Y 64) до бедрока (Y −64): установка, расчистка зоны из Litematica, все 88 команд с поиском и правда про X-ray.

Сайт: https://magomedovex-code.github.io/baricom/

Версии: Baritone 1.17.0 · Minecraft 1.21.11 · Fabric · Litematica 0.26.11.

Статика: `index.html`, `assets/style.css`, `assets/app.js`. Сборка не нужна. Неофициальный проект, не связан с авторами Baritone и с Mojang.
