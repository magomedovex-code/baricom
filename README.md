# baricom

Все 88 команд [Baritone](https://github.com/cabaletta/baritone) на русском — и для каждой своя анимация: нажимаешь на команду, и пиксельный бот показывает её в деле. Плюс правда про X-ray.

Сайт: https://magomedovex-code.github.io/baricom/

Статика: `index.html`, `assets/style.css`, `assets/app.js`, `assets/sim.js` (изометрический мир и сцены команд). Сборка не нужна. Неофициальный проект, не связан с авторами Baritone и с Mojang.
