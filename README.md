# baricom

Неофициальный гайд по [Baritone](https://github.com/cabaletta/baritone) на русском: установка, все команды, расчистка области из Litematica и риски на серверах.

Сайт: https://magomedovex-code.github.io/baricom/

Версии: Baritone 1.17.0 · Minecraft 1.21.11 · Fabric · Litematica 0.26.11.

Сайт статический (HTML + CSS), без сборки. Не связан с авторами Baritone и с Mojang.
